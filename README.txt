KEIMWERK – PROJEKTINFORMATIONEN
=================================

Keimwerk v2.5.3 – Wissen, das Wurzeln schlägt.

Diese Ausgabe ist für statisches Hosting über GitHub Pages bestimmt.
Startseite: index.html
Werkzeuge und Wissensbereiche: bereiche.html
Düngerrechner: app/calculator.html (auch über die Website erreichbar)

Die Website funktioniert ohne eigene Serverinstallation. Teile der
Kontakt- und Analysefunktionen können externe Dienste voraussetzen.
Grow-Tagebuch, Favoriten und andere persönliche Daten werden lokal im
jeweiligen Browser gespeichert. Sie werden nicht automatisch zwischen
Geräten, Internetadressen oder Browsern synchronisiert. Verwende die
Datensicherung auf der Website, um lokale Daten zu übertragen.
